**投光实机验证步骤：**

1. 手动导入本包，替换旧版；不自动部署。
2. 启用另外安装的 Helmet Headlamp 1.0.0 资源选项：`Default Mode - Gameplay` 或 `Default Mode - Task Light`。
3. MOM → 飞鹰方向指引 → **原生红色投光验证（需头灯资源）** → 开启并应用。
4. 召唤飞鹰，观察落点附近地面/岩石是否真实被红光照亮，方向及亮度是否合适，结束后是否清理。
5. 关闭此测试开关并应用，确认灯光立即消失；验证后建议保持关闭。

原型为每个落点上方 12 m 的独立向下聚光灯，只验证附近原生照明，尚不覆盖完整矩形打击范围，
没有刺魟的投影纹理。开启时隐藏 rc8 整块半透明覆盖；关闭后保留原覆盖开关的设置。
资源/API 不可用时只省略灯光，日志记录原因。普通指引不需要头灯；本包不包含第三方资源或代码。
不改已有头灯实例或设置，无 HD2Runtime 依赖。

每帧最多创建一个灯光，静止后不重复更新位置/颜色，没有活跃数量上限或额外地形查询。
结束、关闭、绘制失败和退出均清理；场景销毁后不向旧 world 调用销毁。

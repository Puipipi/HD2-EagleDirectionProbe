## 类型读取与关联

`stratagem_query.lua` 仅用 Windows 当前进程的有界 ReadProcessMemory 快照，没有游戏原生函数调用、
内存写入或 HD2Runtime 依赖。模块加载和构造时不初始化原生适配器。世界必须是实际主世界且仍在世界列表，
随后检查现有地形契约的 PE 时间戳、映像大小、x64 标志和代码指纹；代码指纹最多每秒核查一次。
这是运行期 PE/代码检查，**不是每次快照计算整个游戏文件的 SHA256**。
两个磁盘 SHA256 匹配的只读证据见 [参考分析](eagle-hud-reference-1.1.1-analysis.md)。

读取任务状态和身份、活跃记录管理器、数量、数组，最多接受 512 条原生记录；这是损坏数据的边界检查，
不是显示数量淘汰。64 字节记录一次批量复制，最多 32768 字节；检查指针、短读、坐标及复制前后表头、
管理器、任务/世界一致性。表头一致不能保证每条记录绝对原子，因此关联还需要两次稳定观察。
其他类型也保留为位置歧义阻挡，只有目录中的八类允许被赋值。

有活跃指引且任一类型选项开启时，每 0.2 秒读取一次；失败后 5 秒重试。
球与记录需满足 XY 距离不超过 2 m、Z 差不超过 6 m，且双方互相只有一个候选。
连续两次相同类型、附近位置，间隔至少 0.12 秒且不超过 1 秒，才确认名称。
这依然是**实验性空间关联，没有唯一原生事件 ID、owner 或飞机 ID**。
过近的并发呼叫、未知类型、球弹跳或尚未出现的记录可能保持未知。

未识别时读取失败/歧义继续显示原通用走廊。已两次确认的类型在记录消失或查询失败后保留到该指引结束，
避免攻击中途名称和范围反复跳变；任务/世界身份切换清除旧匹配，新球不会继承旧标签。
类型读取器只改名称与参考形状，不改球的位置、实际飞机朝向、离场冻结轴或结束规则。

## 开销与离线验证

地形两模块与 1.9.10 原始字节一致。每条走廊仍 21 × 3 粗网格（63 点），全局每帧最多两次查询、
0.5 ms 软预算。参考宽度变化时重建一次该球的网格；宽圆区域的横向采样因此更粗。
缓存完成后不因动效新增查询。软预算不能中断一次原生查询。

165 项测试通过，新增测试覆盖有界二进制读取、错误构建/指纹/任务/世界/指针/数量/短读、撕裂表头、
非有限坐标、24 并发记录、两次互相唯一关联、未知类型歧义、身份切换、显示形状、菜单保存和查询预算。
审查发现的未知记录过滤问题已先复现再修复；短圆范围箭头空相位同样有回归测试。
六个打包资源经过真实 LuaJIT 编译。ZIP 校验、封面及源码字节一致性由打包验证器检查。

基准：`python -B tests/offline/benchmark_render.py --baseline-ref v1.10.0-rc1 --solid-fill --types --repeats 3`。
另加 `--type-id 3` 覆盖圆形。140 fps 模拟，预热 600 帧，再测 280 帧，三次取中位数：

| 场景 | 1 / 4 / 8 指引的 Lua ms/帧 | 分配 KB/帧 | 线段/帧 |
| --- | --- | --- | --- |
| rc1 通用走廊（空袭对照运行） | 0.0412 / 0.0956 / 0.2391 | 15.21 / 48.71 / 93.34 | 244 / 977 / 1954 |
| rc2 空袭参考带 | 0.0329 / 0.0922 / 0.1529 | 14.33 / 45.19 / 86.24 | 222 / 889 / 1778 |
| rc2 500kg 参考圆 | 0.0279 / 0.0693 / 0.1480 | 12.29 / 36.99 / 69.82 | 247 / 990 / 1979 |

测量段无静态地面重建或新增地形查询，每组仅 10 次类型快照。范围缩短减少了部分几何工作，
圆形白线更多。**原生渲染及类型读取为模拟，不包括真实 RPM、解析、GPU 或游戏引擎成本，不能换算成 FPS。**
没有给全部类型或任意并发数量作性能承诺。

## 需要用户实机操作

1. 手动导入 `dist/HD2-EagleDirectionProbe-1.10.0-rc2.zip`，保留 1.9.10 回退包。
2. 普通任务先投空袭、集束、500kg，观察名称、条带/圆心位置与实际来袭方向。记录是否仍为 EAGLE ?。
   再投扫射检查窄带向前；110mm 应仅标目标未知，不出现伪造目标圆。
3. 队友同时在分开的落点投不同战备，检查独立名称、范围和结束；重叠球应允许未知。
   飞鹰风暴无当前可测试星球，仍不声称完整支持。
4. 侧看天空 →、俯看地面三角、检查光片与菱形的真填充。切换 MOM 三个实验选项、退出重启核对保存。
   开启透视会回退线段。确认攻击退场后和退出任务后无残留。
5. 比较多人并发性能。如异常，先关闭类型/范围或真填充，必要时回退 1.9.10。
   保留加载器日志中的 `stratagem reader`、`type candidate`、`true fill` 行及对应截图。

原生世界 GUI 材质、遮挡、双面显示及临时内存配合仍未任务内验证。pcall 只能捕获 Lua 错误，不能证明原生调用无故障。
安装包不包含第三方原始脚本、游戏二进制或私有快照，没有自动导入/部署游戏。

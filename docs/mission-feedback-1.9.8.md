# 1.9.8：离场稳定、MOM 独立开关与性能

用户反馈：抬升离场时地面与天空方向左右摆动；要求四项独立、默认开启、保存配置；多人反馈开销较大。

## 原因与修改

旧逻辑在机头竖直分量 ≤ 0.3 时仍把飞机朝向写入落点。浅角度抬升的撤离转向因此旋转了整个地面和天空指引。
现在攻击区内经历过俯冲后，机头向上或低点上方保持水平的阶段暂停落点方向更新。
机头旁的箭头继续跟随机体；重新俯冲或回到低点平飞会恢复更新。离场确认/查询缺失的退场期限保持原值。
这依据姿态及高度判断，无法从公开脚本可靠读取“最后一颗弹药已释放”事件，仍需实机验证。

MOM 四个默认开启项：飞鹰指示箭头（含尾迹）、天空方向箭头、地面走廊边框、地面走廊三角。
透视显示仍默认关闭。任一地面选项开启时显示中心菱形；天空单独开启也能正常绘制。
参考 `mods/stratagem-cooldown/src/vehicle_cooldown.lua` 的 MOM 注册顺序：register → get 恢复 → set 同步有效值。
回调仅更新普通 Lua 状态；保存由 MOM 执行，点击“应用”后生效。没有新增配置文件或 Runtime 依赖。
保留深度和天空已有选项 ID；旧版整体地面开关被拆分为两个新 ID，新项默认开启。

性能改动不改变实心密度、大小、数量或查询精度：

- 地面边框/落点使用独立缓存，飞机移动只重建飞机图形。
- 双线性高度插值用标量，取消每次插值的五张临时表。
- 动画签名复用已生成的地面签名，避免每帧重复排序/格式化落点。
- 退场/隐藏/释放时丢弃相关几何缓存。原生地形模块保持字节一致。

## 可复现验证

新增回放最初 5 项中 4 项失败：浅角度撤离摆动、缺少独立选项、保存值未恢复、飞机移动重建地面。
补充的“抬升后暂时平飞继续转向”用例也先失败，再修复。当前 127 项通过。
原来的俯冲入场转向、短暂抬头、同机多帧查询漏失、多球、远端山脊、全局每帧 2 次预算仍通过。

```powershell
python -B -m unittest discover -s tests -q
python -B tests/offline/benchmark_render.py --baseline-ref v1.9.7 --repeats 5
python -B work/standalone/build_probe.py --validate-only
python -B work/standalone/build_probe.py
python -B work/standalone/verify_package.py
```

基准：同机 LuaJIT 2.1、140 Hz 更新、20 Hz 飞机位置变化、完成的平地碰撞缓存；每场景 280 帧，交替运行两版本各 5 次取中位数。
为单独测量分配量，测量段暂停 GC；模拟原生绘图接口，不保留测试框架的绘图历史。预热 600 帧。

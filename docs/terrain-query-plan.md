# 独立地形查询实施记录（2026-10-09）

用户授权接入不依赖 Runtime 的碰撞高度查询，保持手动导入。

1. 先用真实 LuaJIT 驱动模组，复现远端山脊仍按信标高度绘制的问题。
2. 独立查询模块仅负责已验证的原生查询边界。由已安装 BTO 的查询契约核对当前游戏
   二进制，固定版本、完整代码匹配、物理世界/预设/单位检查失败时不调用。
   不修改游戏内存，不安装 Runtime，不直接执行未验证地址。
3. 绘图模组对整条 200 m 走廊建立三列、10 m 步长高度网格。全局每帧最多两次，
   0.5 毫秒软预算，轮流处理活跃走廊。缓存与该走廊同生命周期；明显转向刷新。
   查询缺失处不连接假平地；接口不可用时报告原因并回退原信标显示。
4. 测试远端山脊、查询总预算、缓存、多走廊、公平性、退场、转向、原生前置检查。
   校验当前实际游戏文件的代码契约；运行全套检查、打包并核对包内源码。
5. 记录实机查询总量与峰值耗时。离线测试不能替代实机性能和观感验收。

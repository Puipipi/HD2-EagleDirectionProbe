# 1.10.0-rc6 绘制优化与贴地修正

本轮回应继续减轻性能开销，以及走廊/三角浮空、光片不要透明的反馈。

## 显示修正

- 地面边框和移动三角的固定离地抬升从 0.8 m 降至 0.08 m。保留 8 cm 余量避免共面闪烁，减少平地悬浮遮挡。
- 地形仍使用原粗缓存插值；降低抬升不等于提高采样精度，急剧起伏处仍可能存在误差。
- 竖立菱形/光片使用独立旧高度，天空箭头高度不变。
- 光片底板、边缘与文字 alpha 均为 255；底板为深红 RGB 68/8/16，配亮红边缘与浅色文字。
- 不透明底板内外各放一份字，距各自表面 4 cm，内侧字反转布局以正常阅读。
  500kg 的弧形光片增加少量底板分段，防止底板弦面遮住内侧文字。
- 实心光片每条长边改为 1～2 块，增大间隙，减少不透明板挡视野，并抵消双面字的绘制负担。
  文字和光片仍一起移动；线段回退保留原密度，线模式没有实体遮挡底板。

## 性能改动

- 每个逻辑三角形仍画正反两面，但同一次提交只创建三个原生顶点，两面共用。
  创建传 XYZ、更新传 XZY，保持原坐标修复。
- 已保留且索引未变的不可变面片记录，不再重复校验顶点；所有变化面片仍整体校验后才调用原生接口。
- 真填充模式缓存普通 Lua 线段列表，不再每渲染帧遍历所有字形/光片三角形寻找线段。
- 没有线段且保留面片未变化时，不创建用不到的当前帧 Color。
- 光片模板提前合并同一横向位置/深度的字形顶点为“列”，同列上下顶点共用地形插值。
  每面只计算各自列的水平位置与高度，使用标量数组，避免逐角点重复查询缓存或创建临时列坐标对象。
- 线段回退直接使用原批次，每渲染帧 reset/dispatch。隐藏、释放和模式切换清理列表缓存。
- 所有缓存只保存普通 Lua 数据，原生 Vector3/Color 均在当前帧创建使用。

20 Hz 动效、10 m/s 移动速度、指引退场、MOM 配置、类型识别频率和全部指引数量不变。
没有添加活跃指引数量上限，没有新增碰撞查询。原生地形两资源与 v1.9.10 字节一致；
21×3 点缓存、全局每帧最多两次查询和 0.5 ms 软预算保留。无 HD2Runtime 依赖。

## 最终候选的离线测量

仓库根目录顺序运行：

```powershell
python -B tests/offline/benchmark_render.py --baseline-ref v1.10.0-rc5 --solid-fill --types --frames 1120 --repeats 7
python -B tests/offline/benchmark_render.py --baseline-ref v1.10.0-rc5 --types --frames 1120 --repeats 7
```

真实 LuaJIT 2.1 更新路径；140 Hz 渲染、20 Hz 飞机运动/动效、5 Hz 类型快照；模拟空袭参考条带。
每次先预热 600 帧；基线与候选交错测量，各七次取中位数。基线同时加载旧主脚本和旧实心渲染器。
原生 API 为轻量模拟，因此计时不包含真实引擎/GPU 成本，分配量也不能当作原生内存消耗。

真填充场景（ms/渲染帧）：

| 同时指引 | rc5 | rc6 | 离线 Lua 耗时减少 |
| --- | --- | --- | --- |
| 1 | 0.0436 | 0.0326 | 25.2% |
| 4 | 0.1656 | 0.1249 | 24.6% |
| 8 | 0.3299 | 0.2639 | 20.0% |

三个场景原生顶点构造约减少 54.1%，颜色构造从每帧 15 次降至约 4.29 次，减少 71.4%。
该空袭场景最终驻留原生三角数约减少 7.1%（单路 1134→1054），这是间隔变大的光片与双面字合并后的结果。
类型快照次数保持一致；预热后地形重建与碰撞查询仍为零。不同战备、动画相位的面片数量和收益会变化。
模拟 Lua 分配量在八路场景略增（247.47→248.88 KiB/帧），因此不宣称整体内存用量下降。

线段回退的图形和原生构造次数未变，计时分别为 0.0412→0.0431、0.1571→0.1561、0.3287→0.3233 ms，
有小幅正负波动，不宣称回退模式有明确速度提升。
完整数据：[真填充基准](benchmark-1.10.0-rc6-solid.json)、[线段基准](benchmark-1.10.0-rc6-lines.json)。

此前单独性能改动约降低 11%～14% 的测量已被以上最终候选取代。
更大的顶点哈希缓存反而增加 Lua 开销，已撤回；直接给每块原密度光片补双面字也明显增加开销，
因此最终采用更稀疏的双面板与按列插值。**这些数字不是游戏 FPS 提升比例。**

## 验证与手动验收

186 项离线测试通过。新增三项性能回归覆盖同次调用顶点复用、未变化帧颜色构造、
混合创建/更新的坐标与原生帧生命周期；两项效率检查在未修改的 rc5 上失败，在候选上通过。
四项显示回归覆盖平地/斜坡、近端/远端、实心/线段的离地高度、碰撞预算、不透明颜色，
以及直带/500kg 圆带的内外标签、内侧字方向、实际底板弦面遮挡关系；先复现失败再修复。
原有模式切换、透视、API 故障回退、140 Hz 提交、世界消失和指引清理继续通过。
六资源 LuaJIT 编译、封装内容一致性及原生地形字节不变由构建校验确认。

沿用 GUID，用户手动导入，不自动部署或操作游戏。
用相同场景和 MOM 配置对照 rc5/rc6 的单路/队友多路帧时间；
检查平地与坡面的贴地、闪烁，光片不透明底板及两侧文字、弧形板文字、流动与退场清理。
实际 FPS、原生材质和复杂地形遮挡仍需实机确认；警戒光片仍可用原有 MOM 开关独立关闭。

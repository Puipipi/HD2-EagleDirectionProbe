# v1.9.7 — 飞鹰来袭指引

显示飞鹰的实际飞行方向、落点附近的天空箭头和贴地走廊。依赖 **Bingus Shared Loader v15+ / API 1**，不依赖 HD2Runtime，也不需要安装弹道显示模组。

本次发布包含：

- 五枚竖直「→」天空箭头，带实心箭杆和尖头，中心位于当地缓存地形上方约 12 米，沿来袭方向移动。
- 贴地走廊与实心流动箭头；中心金色菱形放大至约 2.8 米。
- 不按数量淘汰活跃走廊，确认飞机离场后同步清除天空和地面提示。
- 修复重新飞行、已退场对象再次投掷，以及资源查询漏失导致不再显示的已复现路径。
- 透视默认关闭，可在 Mod Options Menu 中切换透视、天空箭头和地面走廊。
- 模组封面，可在管理器中显示。

下载附件 `HD2-EagleDirectionProbe-1.9.7.zip`，直接导入模组管理器；启用 Shared Loader 与本模组后部署。更新旧版时使用同一模组条目，避免并行启用多个版本。不要把 GitHub 自动生成的 Source code ZIP 当作安装包。

已通过 **122 项离线检查、真实 LuaJIT 编译、安装包 CRC 与源码一致性校验**。地形为约 10 米步长的粗采样，全局每帧最多两次查询并复用缓存；尖锐起伏仍可能穿线。最新外观与性能仍需实机验收。

具体飞鹰战备类型尚未可靠识别，走廊不代表伤害范围；无普通信标的飞鹰风暴仍有落点识别限制。实心效果使用密排线条，极近观察可能看到线纹。
